## 一、全局约定

### 1.1 统一响应格式

```json
{
  "code": 200,
  "message": "操作成功",
  "data": {},
  "timestamp": 1717234567890
}
```

| code | 含义 | 触发条件 |
|------|------|---------|
| 200 | 成功 | 正常返回 |
| 400 | 参数错误 | @Valid 校验失败 |
| 401 | 未登录 | Token 缺失或过期 |
| 403 | 无权限 | 无对应权限码 |
| 404 | 资源不存在 | ID 查不到 |
| 500 | 服务端错误 | 未捕获异常 |

### 1.2 分页响应格式

```json
{
  "code": 200,
  "message": "操作成功",
  "data": {
    "list": [],
    "total": 0,
    "pageNum": 1,
    "pageSize": 10
  }
}
```

### 1.3 鉴权规范

- 请求头：`Authorization: Bearer {token}`
- 白名单接口（无需鉴权）：
  - `POST /api/auth/login`
  - `POST /api/auth/register`
- Token 有效期：24 小时
- 401 处理：前端统一拦截器 → `/login`

### 1.4 分页与排序

| 参数 | 说明 | 默认值 |
|------|------|--------|
| pageNum | 页码 | 1 |
| pageSize | 每页条数 | 10 |
| sortField | 排序字段 | create_time |
| sortOrder | 排序方向 | desc |

## 三、线索模块

### 3.1 接口清单

| 方法 | 路径 | 权限码 | 说明 |
|------|------|--------|------|
| GET | `/api/clue/page` | `clue:list` | 分页列表 |
| GET | `/api/clue/{id}` | `clue:list` | 详情 |
| POST | `/api/clue` | `clue:create` | 新增 |
| PUT | `/api/clue` | `clue:edit` | 编辑 |
| DELETE | `/api/clue/batch` | `clue:batchDelete` | 批量逻辑删除 |
| GET | `/api/clue/{id}/follow` | `clue:list` | 跟进记录列表 |
| POST | `/api/clue/follow` | `clue:edit` | 新增跟进 |
| POST | `/api/clue/{id}/convert` | `clue:convert` | 线索转项目 |
| POST | `/api/clue/import` | `clue:import` | Excel导入 |
| GET | `/api/clue/export` | `clue:export` | Excel导出 |

### 3.2 分页列表 `GET /api/clue/page`

**请求参数**：
| 参数 | 必填 | 说明 |
|------|------|------|
| pageNum | 否 | 默认1 |
| pageSize | 否 | 默认10 |
| keyword | 否 | 线索名称/公司模糊搜索 |
| owner | 否 | 承接人筛选 |
| status | 否 | 线索状态筛选 |
| level | 否 | 项目等级筛选 |
| dateFrom | 否 | 留痕日期起 |
| dateTo | 否 | 留痕日期止 |

**返回 data 结构**：
```json
{
  "list": [{ "id":1, "clueName":"", "clientCompany":"", "beikeOwner":"", "clueStatus":"", ... }],
  "total": 72,
  "pageNum": 1,
  "pageSize": 10
}
```

### 3.3 新增线索 `POST /api/clue`

**请求体**（必填标*）：
```json
{
  "clueName": "xxx项目需求",         // *
  "clientCompany": "某科技有限公司",   // *
  "clientDept": "技术部",
  "clientContact": "张三",
  "beikeOwner": "李四",              // *
  "budget": "10-50万",
  "clueLevel": "B",                  // *
  "deptBelong": "平台一部",          // *
  "clueStatus": "线索接触",          // *
  "requirementDesc": "...",
  "clueEvaluation": "中等价值",
  "contactDate": "2026-07-01",
  "remark": ""
}
```

### 3.4 线索转项目 `POST /api/clue/{id}/convert`

**请求体**：
```json
{
  "projectName": "xxx项目（默认使用线索名称）",
  "projectManager": "李四（默认使用承接人）",
  "projectAmount": 50.0
}
```

**映射规则**（线索 → 项目）：
| 线索字段 | → | 项目字段 |
|---------|---|---------|
| clueName | → | projectName |
| clientCompany | → | clientName |
| beikeOwner | → | projectManager |
| budget（转换） | → | projectAmount |
| clueLevel | → | projectLevel |
| deptBelong | → | deptBelong |
| requirementDesc | → | description |
| arUserId/srUserId/frUserId | → | 直接继承 |
| id | → | sourceClueId |

**联动操作**：
1. 线索 `clueStatus` → `已转项目`
2. 线索 `isConverted` → `true`
3. 线索 `relatedProjectId` → 新项目ID
4. 自动记录操作日志
