## Git 分支对应关系

```
main ─── feat/frontend-auth-integration ─── feat/frontend-leads-list ─── feat/frontend-leads-detail
                                                                              ↓
                                                              feat/frontend-projects ─── feat/frontend-portal

                                                                              feat/frontend-system-admin ─── feat/frontend-polish
```

每个任务完成 → `git merge` → 基于新 main 开下一个分支。
